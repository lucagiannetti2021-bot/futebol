Principais conclusões

Após a limpeza dos dados, o projeto pode destacar conclusões como:

A maior parte dos jogadores está entre 20 e 30 anos.
Existe forte relação entre Overall e valor de mercado.
Jogadores jovens apresentam maior diferença entre Potential e Overall, indicando margem de evolução.
Clubes com elencos mais valiosos tendem a concentrar atletas com maiores notas.
Algumas posições, como goleiros e zagueiros, apresentam maior altura média.
Os salários acompanham, em geral, o desempenho dos jogadores, embora existam exceções.

Esses insights demonstram capacidade de transformar dados brutos em informações úteis para tomada de decisão, um dos principais objetivos de uma análise exploratória de dados (EDA).
